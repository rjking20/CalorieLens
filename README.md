# CalorieLens

AI-powered calorie tracking app built with React Native (Expo).

## Features
- 📸 Food photo capture & AI recognition (Google Gemini Vision)
- 🔥 Calorie & macro tracking (protein, carbs, fat)
- 📊 Dashboard with charts & progress rings
- 📖 Meal history & food diary
- 🎯 Daily calorie goal setting with TDEE calculator
- 💧 Water intake tracking
- ⚖️ Weight tracking with BMI

## Setup

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm start
```

## Configuration
Add your Google Gemini API key in the app's Profile → Settings screen, or during onboarding.

Get your API key from: https://aistudio.google.com/apikey
